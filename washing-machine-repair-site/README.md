# Washing Machine Repair Service Website

## Overview
This project is a premium design website for a washing machine repair service. It provides users with information about the services offered, brands serviced, and contact details for booking services.

## Project Structure
```
washing-machine-repair-site
├── src
│   ├── index.html          # Main HTML document for the website
│   ├── styles
│   │   └── style.css      # CSS styles for the website
│   ├── scripts
│   │   └── main.js        # JavaScript for interactivity
│   └── images
│       └── logo.svg       # Logo for the website
├── package.json            # npm configuration file
└── README.md               # Project documentation
```

## Features
- **Responsive Design**: The website is designed to be fully responsive, ensuring a seamless experience on both desktop and mobile devices.
- **Service Sections**: Detailed sections for various washing machine repair services.
- **Brand Compatibility**: Information on all brands serviced.
- **Contact Form**: A user-friendly contact form for booking services.
- **Interactive Elements**: JavaScript enhancements for a dynamic user experience.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd washing-machine-repair-site
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Open `src/index.html` in your web browser to view the website.
